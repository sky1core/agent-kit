# GUARDRAILS.md 원칙

프로젝트 루트의 `GUARDRAILS.md`는 다음 에이전트가 같은 실수를 반복하지 않게 막는
금지 목록이다. 실행 checker, 키워드 차단 목록, 임시 분석 노트, 처방 매뉴얼이
아니다.

- 모호하거나 헷갈리게 쓰지 마라. 목표는 분량 축소가 아니라 오독 방지다. 그 항목만
  읽어도 금지 행동, 적용 범위, 금지되는 전환·입력·출력 경계가 드러나야 한다.
- 한 항목은 "X 하지 마라" 형태의 금지 명령으로 써라. 평서문("X 한다", "X 받는다")은
  시킨 건지 금지인지 모호하고, 긍정 명령("Y 해라", "Y 옮겨라")은 처방으로 읽혀
  그대로 구현된다.
- 의미가 흐려질 정도로 압축하지 마라. 추상명사만 두고 이유나 범위를 추측하게 만들지
  마라. 이유는 금지 명령과 함께 써도 된다(권장). 이유를 sub-header나 별도 설명
  블록으로 빼지 마라. 본격적인 설명이 필요하면 스펙이나 설계 문서에 둔다.
- 금지된 필드 이름, legacy 식별자, 잘못된 동작 이름을 나열하지 마라. 이름 나열은
  다른 이름으로 우회된다. 어떤 계층·경계에서 무엇을 선택·해석하면 안 되는지로 써라.
