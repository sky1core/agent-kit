# AGENTS.md 지침 예시

```markdown
- **문서와 주석은 꼭 필요한 것만 최소로 남긴다.** 코드만으로 의도가 명확하면 주석을
  달지 마라. 주석은 사용자가 지시했거나 같은 자리에서 잘못된 수정이 실제로 반복됐을
  때만 "X를 바꾸지 마라 — Z 때문에 깨진다" 형태로 남긴다. 앞으로 잘못 고칠 것 같다는
  예상만으로 예방적 주석을 붙이지 마라. 지시받지 않은 문서를 새로 만들지 마라
  (빌드·CI가 강제하는 문서 파일은 지시로 본다). 도구가 읽는 주석 — shebang, pragma,
  라이선스 헤더, 프로젝트가 실제로 소비·강제하는 docstring — 은 이 규칙의 대상이
  아니다.
```
